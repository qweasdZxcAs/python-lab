Омск 2026
  
Изучить основы работы с системой контроля версий Git и платформой GitHub, освоить создание репозитория, добавление файлов, фиксацию изменений и отправку данных в удалённый репозиторий.  
  
Ход работы  
1\. Создана главная папка python-lab, внутри которой созданы каталоги lab\_01, lab\_02, lab\_03 и lab\_04 для хранения лабораторных работ.  
2\. В главной папке инициализирован локальный репозиторий Git командой:  
git init  
3\. Проверено состояние рабочего каталога командой:  
git status  
4\. Файлы лабораторных работ добавлены в подготовленную область Git:  
git add .  
5\. Создан коммит для сохранения изменений в истории репозитория:  
git commit -m "Add laboratory folders"  
6\. Создан удалённый репозиторий python-lab на платформе GitHub. Локальный репозиторий связан с удалённым с помощью команды:  
git remote add origin [https://github.com/qweasdZxcAs/python-lab.git](https://vk.ru/away.php?to=https%3A%2F%2Fgithub.com%2FqweasdZxcAs%2Fpython-lab.git&utf=1)  
7\. Проверен адрес удалённого репозитория:  
git remote -v  
8\. Основная ветка переименована в main:  
git branch -M main  
9\. Изменения отправлены в удалённый репозиторий GitHub:  
git push -u origin main  
10\. После отправки изменений проверено состояние рабочего каталога:  
git status
